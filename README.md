# Система Управления Спортивными Турнирами

Полноценное веб-приложение для автоматизации организации и проведения спортивных соревнований. Проект разработан в рамках курсовой работы по базам данных.

Система предоставляет единую платформу для организаторов, представителей команд и гостей, позволяя удобно планировать расписание, регистрировать команды, назначать судей и отслеживать результаты матчей.
